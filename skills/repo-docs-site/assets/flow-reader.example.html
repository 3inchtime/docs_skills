报告导出：把图和逐项说明放在一起

合成示例 · 不代表任何目标仓库的实现。

本例设定：日期须填写且开始日不晚于结束日；校验通过后生成 CSV 并返回下载入口，否则返回参数错误。阅读顺序不代表执行路径，具体分支看图中箭头。接入真实文档时按源码替换场景与证据。

日期范围决定是否继续生成文件

图展示分支；下方说明保留每项的输入、动作和结果。按钮只突出当前说明，完整内容始终可读。

  1. 用户提供开始日期和结束日期，例如 2026-11-01 至 2026-11-07。

    输入
    两个日期。
    输出
    交给日期校验步骤的参数。

  2. 两个日期都已填写，且开始日期不晚于结束日期时，继续生成 CSV；任一条件不成立时返回参数错误。

    输入
    开始日期和结束日期。
    结果
    允许继续，或拒绝本次导出。

  3. 把指定日期范围内的数据转换成 CSV 文件。

    前提
    日期参数有效。
    输出
    本次导出的文件。

  4. 文件生成完成后，向用户提供下载入口，本次有效路径结束。

    前提
    文件已生成。
    结果
    用户得到导出结果。

  5. 指出日期参数错误并结束；CSV 生成和下载入口返回均不执行。

    条件
    日期缺失，或开始日晚于结束日。
    结果
    本次请求被拒绝。
