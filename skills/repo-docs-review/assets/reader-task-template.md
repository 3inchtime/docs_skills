# 独立读者任务

读者具备项目所需基本开发能力，不了解本项目业务和隐含规则。

## 读者输入

- 可交付文档入口：
- 要理解的模块或业务场景：
- 必要的阅读边界：

只提供文档和任务，不附源码、作者聊天、预期答案、调查笔记或提示读者应指出的问题。

## 任务

1. 说明业务触发者、输入与最终结果。
2. 按顺序解释主流程，指出首次写入或状态变化。
3. 选择一个真实失败条件，说明触发、停止位置、可见结果及后续处理。
4. 对一个符合现有业务的小改动，找到修改入口、不变量和验证方式。
5. 解释一个业务专有词、适用范围、本系统口径和代码映射。
6. 找到文档对应的代码版本，指出已验证和待确认范围。

每个回答引用页面或小节。找不到时写“文档未提供”，并说明还需要什么信息。
